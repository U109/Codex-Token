Codex Token — 非官方 Windows CDP 运行时增强

显示会话用量、逐回复 Token、缓存命中率、标准价参考和模型输出速度估算。
版本号见同目录 manifest.json 的 releaseVersion，许可证见 LICENSE.txt。

安装与升级
1. 只需下载并运行 CodexToken-Setup-win-x64.exe。已安装时直接覆盖升级，无需先卸载。
2. 保存工作并完全退出 Codex，再从桌面或开始菜单的“Codex Token”启动。
3. 输入框上沿的统计栏查看会话总用量、输入、输出、缓存、命中率和花费。
   点击回复操作栏中的用量图标查看单轮详情；运行中统计位于本轮内容底部。

本工具以普通用户权限运行，不复制或修改官方 EXE/ASAR，不修改 WindowsApps
权限，不迁移聊天、登录凭据或配置，不更改模型和供应商。只安装自身文件与入口。
升级先校验新版、停止同目录助手，再替换文件；失败时恢复旧文件和入口。
安装或升级不会强制关闭官方 Codex。

统计说明
- 本地聊天增量读取 CODEX_HOME（未设置时为用户 .codex）中对应线程的 token_usage_record，
  按 response_id 去重，并用请求用量与累计检查点核对客户端通知。缺少本地记录或远程主机聊天使用通知。
  每约 250 毫秒轮询新增字节；模型请求尚未结束时仍需等待，不按文本长度估算 Token。
- 未收到的数字保持未知，上报的零保留为零。缺少起始事件、跳报或断线时在详情提示“数据不完整”。
- 输入为未命中缓存的输入，输出与缓存读取单独列出，三项相加等于总 Token。
  缓存命中率 = 缓存读取 Token ÷ 全部输入 Token（含缓存）× 100%。没有输入时不计算命中率。
- 完成后保留有效请求用量。重启及页面重载后补读对应文件，与已有精确身份记录对账；
  旧记录只有在本地请求序列完整核对后才替换，不按文本长度或线程累计量补造历史，不补发模型请求。
- 当前会话模型与历史参考模型分别展示。各请求按当时参考型号与上下文档位分别计价。
  本地补读关联同一 turn_id 下先于请求出现的 turn_context.model，恢复历史模型及费用；
  明确的路由通知优先，缺少配置时不借用当前选择或其他回合的型号。
- 会话累计包含屏幕外回合，同轮多条回复只计一次。花费中的约等号表示标准价参考，
  金额后的加号表示只计入已确认价格的部分；未知历史型号不套用当前选择。
- 标准价参考使用 2026-10-15 的离线公开价快照，不代表实际扣款或订阅余额。
- 输出速度（估算）= 已计时请求的输出 Token ÷ 模型交互阶段耗时。扣除工具执行区间，
  并行工具取时间并集，包含输入处理与首 Token 响应。按客户端事件估算，结束后冻结。
  中途接入、历史补读、缺失工具起始或断线时跳过不确定窗口。旧的整轮均速不能换算成此值，显示未记录耗时。
- 运行中快照只在内存中，完成记录保存在官方客户端的页面存储中。
  同轮统计以共享快照保存，减少重复明细占用；旧历史可直接读取。

兼容性与安全
- 通过注册应用身份启动当前用户的官方客户端，使用其默认数据目录与登录状态。
- 运行时启用仅监听 127.0.0.1 的随机调试端口。不要转发端口或执行不可信调试脚本。
- 启动时识别当前页面的必要能力；无法识别时停用增强，原版可继续使用。
  自动发现不代表保证所有未来版本的私有结构兼容。
- 安装器未签名，请从本项目的 GitHub Releases 下载。
- 读取器只读匹配线程的 sessions / archived_sessions 文件；扫描经过包含正文的字节，
  只解析候选用量和回合配置行，向页面和历史传递白名单 ID、Token 数值和参考模型，
  不转发正文、目录、权限、摘要或原始行。
- 诊断日志仅保留兼容性、连接、挂载和用量读取计数，不保存聊天正文、工具参数或凭据。
  日志目录：%LOCALAPPDATA%\CodexToken\Logs。

卸载
在 Windows 设置中卸载“Codex Token（CDP 运行时增强）”。卸载只删除助手自身
文件和入口，不删除官方程序、聊天、登录或页面中已保存的用量统计。
停止或卸载助手不会强制关闭 Codex；完全退出 Codex 才会关闭调试端口。
之后可通过原版入口正常启动。

维护与验证
源码构建：npm run build
构建验收：npm run test:release
