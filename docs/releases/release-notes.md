# 更新记录

### 2026-10-20

#### 0.5.4

- 沿输入框上沿增加一体式统计栏，展示当前聊天的会话总用量、输入、输出、缓存、命中率和花费；跟随客户端配色，调整圆角与左右间距，窄窗口自动换行。
- 会话累计包含屏幕外的历史回合，同轮多条回复只计一次；切换聊天时同步切换。
- 修复会话 Token 总量已补齐、花费却漏算大部分历史请求的问题。根据各请求当时记录的模型恢复标准价参考，明确的实际型号优先；补全型号不重复计数，也不改变速度采样，未知部分不套用当前型号。
- 减少同轮多条回复重复保存明细的空间占用，修复存储空间不足导致记录无法保存的问题；兼容旧历史，区分空间不足、访问受限与历史损坏。
- 本地聊天在一次模型响应结束后读取新增用量，减少等待工具收尾的延迟；说明已经开始出字但统计仍需等待本次模型请求结束的原因。
- 修复同一请求从两个来源到达、或新回合收到上一轮未变化的小计时重复计数的问题；旧报告乱序到达不会回退累计进度、误判漏报或丢失有效速度采样。
- 核对完整的本地请求记录后恢复用量覆盖，修正上下文压缩后持续显示“数据不完整”的误判；中途插入用户消息本身不降低覆盖。
- 支持页面重载、重启和历史补读，兼容日志写入中断、截断、替换及轮转；完整核对后才替换旧统计，不补造缺失的速度或型号。
- 价格详情统一显示“标准价参考”。
- README 增加会话统计栏截图及六个字段的含义说明。

### 2026-10-19

#### 0.5.3

- 将运行中尚无用量时的“等待上报”统一改为“等待回复”。
- 主页面 Token 总量达到一百万时使用 M 展示，保留最多两位小数；详情继续显示完整数值。
- 增加安装器直接下载入口，发布页仅提供一个 EXE 安装文件。

#### 0.5.2

- 修正用量按钮缺少悬停底色的问题，与复制按钮保持一致；详情打开期间保留选中底色。
- 用量统计的悬停提示沿用客户端的圆角、阴影、字体和配色。
- 打开详情后，鼠标移开仍保留所属操作栏；关闭详情后恢复原生显隐，不影响其他回复。
- 切换聊天或复用消息行时关闭旧消息的详情，避免打开状态跟随到另一条回复。

#### 0.5.1

- 修正重启后在已有聊天中完整观测新回合，仍因缺少旧累计基线而误报“数据不完整”的问题；运行中和完成后统一使用本轮观测状态。中途接入、断线和报告不连续仍保留提示，旧历史状态不自动改写。
- 修正运行中用量行的左侧缩进，与工具行对齐；SVG 使用块级布局与固定细线，跟随复制按钮尺寸。
- 移除按钮和总量前的“已观测”、状态中的刷新说明及速度下方的等待说明；数据覆盖不足时保留简短详情提示。
- 分开展示未命中缓存的输入、输出、缓存读取，并增加以全部输入为分母的缓存命中率。
- 速度改为模型交互阶段估算，扣除并行工具区间的并集，仅按有效请求报告累积；结束后冻结。旧记录缺少新计时不换算。

- 展开源码、测试与安装脚本中的压缩语句，增加固定版本的格式化工具、统一命令和 CI 格式检查。
- 将英文代码注释改为中文，将内嵌 C#、PowerShell 测试辅助代码拆为可单独阅读和格式化的文件。
- 按核心逻辑、宿主接入、存储与界面划分源码；将生产界面组件移出实验目录。
- 移除旧改包安装、隔离副本实验、原型页面及其专用测试和命令。
- 删除当前构建不再调用的固定版本校验逻辑及实验账本专用计价入口，统一从 `package.json` 读取发布版本。
- 补充关键模块、统计口径、挂载生命周期和安装事务的中文注释。
- 增加 MIT 许可证、贡献说明、安全说明、开发文档和 GitHub Actions 检查。
- 将构建产物及本机证据与源码分离，安装载荷附带 MIT 许可声明。
