# 架构与代码导航

项目只维护普通用户权限的 CDP 运行时方案。旧的修改官方应用归档方案、隔离应用副本实验、网页原型和独立实验账本不属于当前发布代码。

## 目录职责

| 目录                 | 职责                                                       |
| -------------------- | ---------------------------------------------------------- |
| `src/core/`          | 纯数据校验、消息索引、价格参考、速度与型号名称格式化       |
| `src/host/`          | 本地能力发现、被动通知采集、原生型号订阅、React 挂载与清理 |
| `src/storage/`       | 持久化恢复、写入和存储健康状态                             |
| `src/ui/`            | 消费用量与型号快照的按钮、提示和详情组件                   |
| `packaging/windows/` | C# 安装器、运行助手、PowerShell 安装事务和应用清单         |
| `scripts/`           | 构建、语法检查、载荷验收与可选安装烟测                     |
| `assets/`            | 本项目的 SVG 图标母版、PNG 预览和 Windows ICO              |
| `test/`              | 当前方案的回归测试；`fixtures/` 保存离线价格快照           |

## 数据流

1. `Runtime.cs` 以注册应用身份启动官方 Codex，核对回环调试端点并加载本项目脚本。
2. `cdp-discovery.mjs` 有界读取当前 `app://-` 页面的本地 JS 资源，静态识别 React、解析器和可选型号元数据。
3. `cdp-runtime.mjs` 复用宿主 React，按原生身份属性挂载按钮，管理页面刷新、虚拟化重挂载和资源释放。
4. `desktop-bridge.mjs` 将允许的通知交给 `usage-store.mjs`，再由 `app-server-usage.mjs` 按 host/thread/turn 聚合独立请求。
5. 运行中的快照通过窗口事件发布，完成记录经 `message-usage.mjs` 校验后保存。`token-badge.mjs` 只读取与该消息匹配的数据。

`core` 不依赖浏览器或宿主。`storage` 将显式传入的 Storage 接口连接到采集器；采集器不反向依赖存储。界面不调用采集接口或业务 RPC。

## 必须保持的语义

- **身份**：消息记录以 host/thread/item 为索引，并保留不可换绑的 turn；不能根据消息顺序、URL 或正文推断归属。
- **请求与回合**：通知中的 `last` 是一次请求。线程累计值用于核对连续性，不能直接当作本轮总量。
- **完整性**：缺少起始事件、跳报、断线或计数重置时，详情提示“数据不完整”。完成不会抹去有效请求明细。
- **未知与零**：未知保留 `null` 或缺失状态；上报的零保留为零。整数溢出或矛盾数据不能进入可信合计。
- **恢复**：只从同一条历史记录中校验一致的请求明细恢复缺失小计，不补造未观测的历史。
- **型号与价格**：当前配置和历史参考型号分别展示；每次请求按当时型号、上下文档位计价，再合计。价格不是实际账单。
- **速度**：`model-timing.mjs` 用客户端生命周期估算模型交互窗口，工具执行区间取并集后扣除；只在新用量报告到达时累积有效窗口的输出与耗时。中途接入、工具配对不完整或断线后跳过不确定窗口，保留先前有效样本。新 `modelTiming` 与旧 `observation` 独立，旧整轮均速不能改名当作新速度。
- **输入与缓存**：界面输入为全部输入减缓存读取，缓存写入仍在输入中。输入、输出、缓存读取互斥；命中率以全部输入为分母，没有输入时保持未计算。
- **存储与隔离**：运行中数据不落盘；模拟与真实上报使用独立命名空间。损坏历史保留原文，避免被空索引覆盖。

## 构建与安装

`scripts/bundle.py` 显式列出模块依赖顺序，将具名 ESM 导入转换为私有模块表；不支持的语法直接报错。构建不会下载或打包官方客户端资源，也不包含 React 副本。

`scripts/build.py` 从 `package.json` 读取唯一发布版本，生成运行脚本、辅助程序、包含 MIT 声明的载荷清单和安装器，并记录源码 SHA-256。安装器以嵌入的原始清单校验载荷后再执行管理脚本。

`Manage.ps1` 先在同一父目录准备并校验新文件，再停止同目录助手、替换文件并更新入口。失败时回滚文件及集成状态。路径、目录所有权和链接检查是安装事务的一部分。

## 兼容性边界

宿主私有 React 结构会变化。必要能力无法唯一识别时增强停用；可选型号元数据失败时仍允许统计。自动发现替代了固定版本白名单，但不承诺所有未来版本兼容。

自动化测试覆盖合成通知、身份隔离、数据恢复、界面组件与安装事务。实际宿主中的位置、主题、焦点、模型切换及重启恢复仍需要人工验收，不能用构建通过代替。
