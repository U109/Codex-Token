# Codex Token

为 Windows Codex 桌面客户端增加逐回复用量统计，查看 Token、缓存命中率、价格参考及模型输出速度。当前版本 **0.5.2**。

**非官方项目，与 OpenAI 无隶属或背书关系。** 通过本机 CDP 接口在运行时加载组件，使用普通用户权限，不复制或修改官方客户端文件。

## 界面预览

在每条回复下方，复制按钮旁的用量图标会显示本轮 Token 总量。

![回复操作栏中的用量图标与 Token 总量](docs/images/usage-toolbar.png)

点击用量图标，展开查看模型、价格参考、输入、输出、缓存读取、缓存命中率和输出速度估算。

![用量明细面板，展示模型、价格参考、Token 分类、缓存命中率和输出速度估算](docs/images/usage-details.png)

## 功能

- 在回复操作栏的复制按钮旁查看本轮用量，点击展开输入、输出和缓存明细；输入已扣除缓存读取，三项相加等于总量。
- 用量按钮沿用复制按钮的悬停底色和提示样式；详情打开时操作栏保持显示，关闭后恢复原生显隐。
- 运行时在本轮内容底部刷新统计，完成后保存，刷新页面可恢复已有记录。
- 按请求的参考型号和上下文分别计算公开价参考，区分当前会话模型与历史参考模型。
- 显示模型输出速度估算：输出 Token 除以模型交互阶段耗时，排除工具执行区间。并行工具取时间并集，完成后冻结。
- 支持直接覆盖升级；宿主必要能力无法识别时停用增强，保留原版运行。

缓存命中率为缓存读取 Token 占全部输入的比例。未收到的数据保持未知，覆盖不完整时在详情提示“数据不完整”。速度根据客户端生命周期估算，包含输入处理和首 Token 响应；旧历史没有可用计时时显示“未记录耗时”。本项目不根据文本猜 Token，不补发模型请求，不推算未记录的历史，也不显示实际账单或订阅余额。价格采用 **2026-10-15 离线快照**。

完整性按本轮观测判断：收到回合开始、有效且连续的请求报告并正常结束时，旧聊天缺少累计基线不会影响本轮状态。中途接入、断线或报告不连续时保留部分覆盖提示；旧历史记录的状态不自动改写。

## 安装与使用

需要 Windows x64 和当前用户已安装的官方 Codex 桌面客户端。

1. 从 [Releases](https://github.com/U109/Codex-Token/releases/latest) 页面下载 `CodexToken-Setup-win-x64.exe` 及其 `.sha256` 文件。
2. 核对摘要后运行安装器，已有安装会自动覆盖升级。
3. 保存工作并完全退出 Codex，再通过桌面或开始菜单中的 **Codex Token** 快捷方式启动。
4. 点击回复旁的用量图标查看详情。直接从官方入口启动时不保证加载增强。

```powershell
Get-FileHash .\CodexToken-Setup-win-x64.exe -Algorithm SHA256
```

安装器未签名。运行增强时会启用仅限 `127.0.0.1` 的随机调试端口；不要转发该端口或运行不可信调试脚本。卸载可通过 Windows 设置完成，完全退出 Codex 后调试端口才会关闭。更多说明见 [安全说明](SECURITY.md)。

## 从源码构建

需要 Node.js 22+、Python 3.11+；Windows 构建使用系统的 .NET Framework C# 编译器和 Windows PowerShell 5.1。正常构建无需安装第三方依赖。

```powershell
npm run check
npm run build
npm run test:release
```

`test:release` 包含完整 Windows 回归测试、载荷与来源摘要检查、许可文件检查，以及两个可执行文件的十档图标校验。输出安装器位于 `dist/`。日常仅运行回归测试可使用 `npm test`。

开发时使用 `npm run format` 统一代码格式，使用 `npm run format:check` 检查格式。格式化工具的首次安装步骤见 [开发说明](docs/DEVELOPMENT.md#统一代码格式)。

生成目录 `dist/`、`.artifacts/` 和本机历史实验目录均不会进入 Git 提交。安装包通过 GitHub Releases 分发，源码仓库不分发官方客户端文件或本机验证日志。
